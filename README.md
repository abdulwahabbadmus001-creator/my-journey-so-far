## About the Project

**My Journey So Far** is a personal interactive web experience designed and developed by **Wahab Opeyemi Badmus**.

It started as a birthday website. As I worked on it, the idea became much larger.

Instead of creating a conventional page filled only with birthday greetings and decorations, I wanted to build a digital experience that could preserve parts of my journey — the difficult seasons, the people, the memories, the university years, research, graduation, technology, software development, fellowships, products, gratitude, and the many turns that brought me here.

The result is a combination of:

- **personal memoir**
- **interactive photo archive**
- **birthday experience**
- **product portfolio**
- **visitor guestbook**
- **private time capsule**
- **moderated community interaction**
- **software engineering showcase**

At its heart, the project is about one simple idea:

> **Life rarely moves in a straight line.**

---

## Why I Built It

I did not want my birthday website to only say:

> *Happy Birthday, Wahab.*

I wanted it to answer a more personal question:

> **What has the journey actually looked like?**

There were seasons when education felt uncertain. There were periods of emotional difficulty. There were days of side hustles, washing cars and doing laundry. There was a trip to Epe that unexpectedly introduced me to using a computer. There was university, research, friendship, love, graduation, difficult post-school realities, programming, AI, building products, professional responsibility, fellowships, and continued learning.

Each stage shaped the next one.

This project became a way to use software not only to solve a technical problem, but also to:

- preserve memories;
- document growth;
- tell a personal story;
- acknowledge people;
- create an emotional digital experience;
- and demonstrate what thoughtful software can feel like.

## The Rivers Of My Life

A river does not always move in a straight line.

It bends. It slows down. It meets obstacles. Other streams join it. It changes direction. Sometimes it becomes calm. Sometimes it becomes turbulent. Yet it keeps moving.

That metaphor became the framework for telling my own story.

## Moments Behind the Journey

The project does not treat photographs as a conventional gallery.

Selected images are organised into editorial stories with titles, captions, context and supporting photographs. The current archive includes:

- **Before Any of This** — an early childhood photograph and a reminder that becoming begins before we can name it.
- **The Brother Behind the Push** — a personal tribute to the brother whose support has shaped my education, technology journey and wider family story.
- **Ilorin - Where Research Found Me** — my undergraduate field research journey, including the completed and bound final-year project.
- **Final Year Brethren** — friendships and shared moments from my undergraduate final year.
- **The Gown Was Never Just the Gown** — graduation, persistence and the people who showed up.
- **Learning How the Machine Thinks** — CS50 and Python learning moments.
- **From Learning to Building** — moving from programming exercises into digital products.
- **Abuja - New Rooms, New People** — the Heinrich Böll Stiftung Nigeria Green Academy experience, certificate presentation, farm tour, mentorship and the people who shaped the programme.
- **A Very Short Chess Career** — losing 2-0 to Mr. Ismail after learning chess from Mr. Wisdom.
- **Going Home, Not Going Back** — returning to Lagos after Abuja with new lessons, relationships and perspective.

The purpose is not to show every photograph I have. It is to preserve the ones that help tell the story.

## Design Philosophy

The visual direction is based on:

> **Editorial Minimalism + Emotional Storytelling**

I deliberately avoided building a loud or template-like birthday website.

The interface instead uses:

- generous whitespace;
- oversized editorial typography;
- warm neutral surfaces;
- restrained colour accents;
- asymmetrical layouts;
- minimal borders;
- subtle motion;
- full-screen reading experiences;
- responsive photo stories;
- and calm transitions.

The floating balloons preserve the celebratory identity, while the overall design remains mature and minimal.

The goal is not to impress visitors with the number of effects.

The goal is for the experience to feel **intentional**.

## Date-Based Experience

The application changes according to the date.

### Before October 30

Visitors see a minimal teaser and live countdown.

```text
OCTOBER 30

IN ADDY TO

Wahab Opeyemi Badmus

30 · 10

Days · Hours · Minutes · Seconds
```

### October 30

The full birthday experience unlocks automatically.

### After October 30

The experience can remain available as an archive of the chapter rather than disappearing after the birthday.

## Moderation and Privacy

The application accepts visitor-generated content, so moderation is part of the product architecture.

### Moderated public content

- birthday wishes;
- guestbook messages;
- reader reflections.

### Private content

- Time Capsule messages;
- project enquiries;
- unpublished submissions;
- admin controls.

Sensitive environment files are excluded from version control.

```gitignore
node_modules/
dist/
.env
.env.local
.env.*
```

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/abdulwahabbadmus001-creator/my-journey-so-far.git
```

### 2. Enter the project

```bash
cd my-journey-so-far
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure Firebase

Create a local `.env.local` file with the required Firebase client configuration.

### 5. Start development

```bash
npm run dev
```

### 6. Production build

```bash
npm run build
```

The production build has been validated locally before deployment.

## What This Project Means to Me

There was a point in my life when simply learning how to operate a computer was something new.

Years later, I am using one to build a digital experience capable of preserving parts of my own story.

That contrast is one of the reasons this project matters to me.

**My Journey So Far** is not an attempt to present a perfect life.

It contains uncertainty, difficult seasons, small beginnings, friendships, love, education, side hustles, research, technology, failure, opportunity, learning, building, and continuing.

Building it reminded me that software does not always have to begin with a commercial problem.

Sometimes software can:

- preserve a memory;
- tell a story;
- make someone feel something;
- connect people;
- document growth;
- and demonstrate what the person behind the code is capable of creating.

This repository represents one point in an unfinished journey.

There will be more learning.

More work.

More people.

More products.

More memories.

More chapters.

> **The River Is Still Flowing.**
